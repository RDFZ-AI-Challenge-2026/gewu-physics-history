# 格物 · 重走物理学史（Gewu: Retrace Physics History）

> 像富兰克林、法拉第一样思考：在一个个自然现象前提问、实验、验证，然后看看历史上的物理学家当年是怎么做的。

## 一句话介绍

为一个初中到高中早期的学生，提供一个通过"亲手重走物理学史"来学习物理知识与研究方法的互动网页游戏。

## 我们要解决什么问题

用户不会"遇到困难后主动寻找物理学史游戏"，所以我们的使用理由来自三个具体情境：

- **考试情境（学生）**：初高中物理考试都会考物理学史（富兰克林雷电、伏打电堆、法拉第电磁感应……），学生目前只能死记硬背、容易混淆。走完我们的关卡后，史实变成自己亲历的过程，不需要背。
- **好奇情境（所有人）**：每个关卡以一个反直觉的自然现象开头（梳过头的梳子吸起纸屑、天上的雷电和琥珀吸草屑是同一种东西），先让人愣一下，再引导提问。用户不是带着问题来的，是被现象勾进来的。
- **课堂情境（物理教师）**：物理老师讲到静电、电磁感应等课题时，缺少"让学生先猜、再做、后验证"的课堂导入工具。我们的一关正好是一节 5~10 分钟的探究导入。

在此之上，产品要解决的核心问题是：学生学到的是"结论"，很少有机会体会结论**当年是怎么被提出和验证的**；而教科书式的物理学史（人名、年代、事件清单）记住了故事，没学到**研究的思想与方法**。

## 目标用户

- 初中生：覆盖初中物理知识点（难度标签：初中）
- 高中早期学生：衔接高中内容（难度标签：高中）
- 学有余力者：稍微超纲的延伸关卡（难度标签：延伸）

## 项目规划

- **长期目标**：全面覆盖初高中物理知识，按声、光、力、电等板块组织，以《义务教育物理课程标准》和《普通高中物理课程标准》为知识地图。
- **当前阶段（MVP）**：从**电学**板块切入，先做 2~3 关跑通完整游戏循环：
  1. 摩擦起电：琥珀吸引草屑之谜（泰勒斯 → 吉尔伯特，初中）
  2. 天上的雷电是不是电（富兰克林，初中）
  3. 磁能生电吗：电磁感应（法拉第，高中）
- 循环：呈现现象 → 引导提问 → 模拟实验 → 对照史料 → 下一问。

## AI 在项目中的作用

- **引导提问**：用户自由输入问题，由大语言模型判断其与历史上物理学家问题的接近程度，通过追问引导用户靠近关键问题。这一环节无法用写死的规则实现，是 AI 不可替代的部分。
- **内容组织**：基于权威史料（郭奕玲、沈慧君《物理学史》、人教版教材、原始文献等）组织科普讲解，史实数据由团队人工整理校对，AI 不凭"记忆"生成史实，以保证准确性。
